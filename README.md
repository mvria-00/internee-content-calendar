# Internee.pk – Content Calendar Creation

This repository contains my 2-week social media content calendar created as part of my Social Media Marketing internship at Internee.pk.

## Project Overview

The calendar was created to plan upcoming social media content across different platforms and content formats.

### Platforms

* Instagram
* LinkedIn

### Content Formats

* Single Image
* Carousel
* Reel
* Educational Content

### Calendar Features

* Date-wise content planning
* Platform selection
* Content type
* Captions
* Hashtags
* Post status tracking using a dropdown

## Files

* `Social Media Content Calendar.pdf` — Final PDF version of the content calendar
* `Social Media Content Calendar.xlsx` — Editable spreadsheet version
